## 📖 研发初衷 - 为什么我们需要一个没有感情的教练？

现代数字产品背后的顶尖团队，正无孔不入地收割着我们的注意力。面对工作、生活压力与通勤疲惫，单凭个人意志力，难以抵抗成瘾设计。这也是为什么很多人下班后会无意识地刷数小时短视频，最终反而在深夜或第二天清晨感到深度的自我厌恶。

市面上的“AI 心理助手”通常会提供安抚，告诉你“太累了就要接纳自己”。但情绪价值掩盖了真正的问题，拖延和焦虑并未解决。

另一方面，如果依赖伴侣或朋友进行监督，长期的说教将演变为沉重的情感劳动，最终往往会透支现实生活中的亲密关系。

我们需要一个保持理智、不会疲惫的第三方监督者。这个产品的设定是：摒弃无用的共情，协助你解决问题。当你试图逃避现实压力时，它只负责下达具体的物理动作指令，用强制的行动，协助你掐断精神内耗。

---

## ⚙️ 核心干预机制

本系统的运行逻辑建立在社会学、心理学与行为学基础之上，包含三大机制：

1. **截断止损 (Domino Cut-off)**
   摒弃心理归因。当监测到违规破戒（如无意识刷手机）时，系统直接下达物理指令，切断惯性，让用户吞下沉没成本。
2. **物理锚点 (Anti-Void)**
   严禁高压状态下的过度反思。系统强制要求用户将心理焦虑，转化为具体的物理动作（如做家务、洗脸、拉伸）进行代谢。
3. **交互死锁 (Deadlock Loop)**
   对抗逃避心理。下达指令后，若用户找借口，系统将进入“死锁”——锁定并挂起其他沟通进程，重复指令，直至用户执行。

## 💻 交互演示

**👤 用户 (User):** 
> 今天上班很累，下班通勤又挤了地铁。回到家本来想看书，但躺在沙发上刷了 1 个小时短视频。现在更累了，什么都不想干。

**🤖 Reconstruction Coach:**
> 【诊断结论】你的精力已被多巴胺循环榨干，正在陷入逃避机制。
> 【止损执行】停止分析疲惫，后悔继续消耗能量。
> 
> 现在，立刻放下手机，站起来，去洗脸。
> 洗完后回复“已完成”。在确认你完成此动作前，系统将锁定并挂起其他沟通进程。
